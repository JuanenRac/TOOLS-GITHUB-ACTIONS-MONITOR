# Complète et Lite : le contenu de chaque édition

Deux éditions dans un paquet. **Lite** montre ce qui tourne, les échecs des dernières 24 heures, l'historique et des graphiques de base : ni sentinelle, ni mode réseau, aucun des modules ci-dessous, et rien n'est écrit sur GitHub. **Complète** a tout le reste. Il n'y a pas de troisième édition : ce qui écrit sur GitHub ou sort vers l'extérieur est dans la complète, désactivé tant que vous ne l'activez pas. Les usages (une personne, une équipe, un service) ont leurs propres guides.

# 詳細機能(すべて既定でオフ)

このページの内容は、*設定 > 詳細設定*(または `actions_monitor.json`)でオンにするまで**オフ**です。モニターに誰が到達できるか、GitHub で何ができるかを決めるキーはセキュリティオプションとして印が付いています。必要なものだけオンにしてください。

## ネットワークで待ち受け

既定ではページは `127.0.0.1` でのみ応答します。`listen.network` をオン(再起動が必要)にすると `listen.host` でも待ち受けます。このPCのプライベートアドレス、または全インターフェースを表す `0.0.0.0` です。公開アドレスは拒否されます。

- **すべてのリクエストにアクセストークンが必要**です(Cookie、`X-Monitor-Access` ヘッダー、または `Authorization: Bearer`)。トークンは `listen.token_env` で指定した環境変数の値(16文字以上)で、無い場合は起動のたびにランダムなトークンが作られ、コンソールに一度だけ表示されます。そこに表示されたアドレスを一度開くと Cookie が設定され、きれいなアドレスに移動します。
- ページの使い捨てトークンは強制され、モードがオンの間は全タブに赤いバーが表示され、`listen.*`、`github_token.*`、`act.*`、`github_actions.*` のキーはこのPC自身からのみ変更できます。
- `listen.allowed_hosts` はページを開ける名前の一覧です(DNSリバインディング対策)。
- **リスク。** 通信は暗号化されないHTTPです。ネットワークを盗聴できる人はトークンとデータを読めます。信頼できるネットワークでのみ使うか、HTTPS のリバースプロキシを前に置いてください(`DEPLOYMENT.md` を参照)。インターネットには絶対に公開しないでください。LITE版はこのPCの外では待ち受けません。
- **HTTPS。** 自分の証明書と鍵(`listen.tls_cert_file`、`listen.tls_key_file`)を指定すると、モニター自身が HTTPS を提供します。プロキシが HTTPS を担当する場合は `listen.secure_cookie` を設定してください。どちらの場合も、ブラウザーは変更のたびに `Origin: https://ホスト:ポート` を送り、検査はセッションのスキームだけを受け付けます(別のスキーム、別のホスト、別のポート、不正な形式のオリジンは拒否)。ブラウザーが使うアドレスにはモニターのポートが含まれている必要があります。ただし、既定の 443 番で `Host` と `Origin` をポートなしで転送する HTTPS プロキシの後ろでは、その公開名を `listen.proxy_public_host` に指定してください(ホスト名のみ、既定は空)。HTTPS のときだけ有効で、ポートなしで受け付けるのはその名前だけであり、変更できるのは同じコンピューターからだけです。
- **POST でセッションを開く。** `?access=` 付きのアドレスは非推奨です。既定では引き続き動作し(設定済みのものは壊れません)、`GET` のときだけ有効ですが、トークンは履歴・ログ・`Referer` に残り、モニターは `Deprecation` ヘッダーで応答します。`listen.query_access` をオフにすると拒否され、セッションは `POST /api/access` またはヘッダー `X-Monitor-Access` でのみ開けます。トークンはアドレスバー、履歴、ログに残らず、Cookie は応答で返ります。`?access=` 付きのアドレスも引き続き使えます。`listen.host` が `0.0.0.0` のとき、設定の上部に赤いバーで警告します。スキーマが secure とするすべての設定(`listen.*`、`github_token.*`、`act.*`、`github_actions.*` だけでなく、Webhook、AI アクション、通知、OpenTelemetry、ミラー、ランナー、出力も)は、そのコンピューター自身からのみ変更できます。
- **ネットワークで待ち受けるときの最初の手順。** まず `listen.query_access` をオフにし (トークンがアドレス・履歴・ログに残らなくなります。セッションは `POST /api/access` またはヘッダーで開きます)、その前に HTTPS (`listen.tls_cert_file` の証明書または HTTPS プロキシ) か VPN を置いてください。古いアドレスがまだ受け付けられている間にネットワークモードを始めると、コンソールが同じ注意を表示します。

## モニターが保持する GitHub トークン

既定は引き続き自分の `gh` ログインです。`github_token.enabled` をオンにすると、設定 > 詳細設定でトークンを貼り付けられます。トークンはシステムの安全な保管庫(Windows DPAPI、macOSキーチェーン、Linux Secret Service)に、無い場合のみ権限600のファイルに保存されます(ページに表示されます)。`actions_monitor.json`、ログ、バージョン情報パネル、サポート用テキストには決して書かれず、プロセスの環境経由でのみ `gh` に渡ります。**トークンを削除**ボタンですべての場所から消去します。

## GitHub への操作

`github_actions.enabled` をオンにすると、失敗した実行の再実行(`rerun_failed`、`rerun_run`、`rerun_job`)、実行のキャンセル(`cancel`)、Issue やプルリクエストのクローズ(`close_issue`、`close_pr`)、マージ(`merge_pr`、`github_actions.merge_method` を使用)ができます。使えるのは `github_actions.allowed` にある名前だけです(既定は `rerun_failed` と `cancel`)。**各操作は個別に確認されます**。ページは送信内容(メソッドとエンドポイント)を正確に表示し、そのプランを使い捨てトークンで確認するまで何も送りません。GitHub トークンには権限が必要です(実行には `workflow`、Issue とプルリクエストには `repo`。なければ GitHub の拒否が表示されます)。すべての試行は `github_actions_log.jsonl` に記録されます。AIアシスタントはこれらを開始できません。

## act でここでワークフローを実行

`act.enabled` をオンにし、`act.allowed` に `リポジトリ:ファイル.yml:イベント` の項目(3つとも完全一致)を入れると、正確なコマンドラインを確認した後、ボタンでローカルクローンに対して `act` を実行します。実際のシークレットは渡されません(シークレット・変数・環境・入力のファイルは空、トークンのない最小限の環境)。出力は逐次表示され、一度に1回だけ実行され、`act.timeout_seconds` の時間制限があり、停止もできます。

## アーティファクトのローカルコピー

`mirror.enabled` をオンにし、このPC上の `mirror.folder` を指定すると、完了した実行のアーティファクトがそこにコピーされます(1サイクルあたり `mirror.max_per_cycle`、フォルダー全体で `mirror.max_mb`、保持 `mirror.keep_days`)。各1回のみで、名前はフォルダー内で整形されます。

## セルフホストランナー

`runners.enabled` をオンにすると、設定 > 詳細設定に各ランナーが待機・使用中・オフラインで表示されます。ディスクと負荷は `runners.metrics`({名前: このPCまたはプライベートアドレスの node exporter のアドレス})に載せたランナーだけ表示されます。

## OpenTelemetry

`otlp.enabled` をオンにして `otlp.endpoint`(HTTPS、またはこのPC上のHTTP)を指定すると、完了した実行がトレースとして、ヘッダーの数値がメトリクスとして送られます(JSON の OTLP/HTTP)。各実行は1回だけです。送るのはリポジトリ、ワークフロー、ブランチ、イベント、結果、所要時間だけです。

## 組織とコスト

- `organizations.discover` は設定 > 基本にログインの組織を一覧表示します。1つを監視するには、`github_owner` をその組織にした2つ目のモニターを起動してください。
- `finops.jobs_per_cycle` を0より大きくすると、1サイクルあたりその数の完了した非公開実行のジョブのラベルを読み、仮定した1つのシステムではなく正しい倍率(Linux、Windows、macOS、`quotas.json` の大型ランナー)で分を計算します。請求レポート(`quota.billing_api`)をオンにすると、Codespaces と Packages の金額、使用中のストレージ、含まれる分を超えた分の料金も表示されます。

## 実サービスでの確認

`python tools/manual_check_live.py`(リポジトリ内)は、トークンのスコープ、請求レポート、組織、ランナー、`gh copilot` のフラグを読み取り、動作中のモニターにチャネル経由でテストメッセージを送らせます。シークレットは決して尋ねません。

## 安全上の注意（オンにする前にお読みください）

- **ネットワークモード**: 信頼できるネットワークでのみ使ってください。アクセストークンは暗号化の代わりにはならず、平文の HTTP ではトークンとデータがそのまま流れます。前段に HTTPS プロキシを置く（`listen.secure_cookie` を設定）か、モニターに自分の証明書と鍵（`listen.tls_cert_file`、`listen.tls_key_file`）を渡してください。その場合は自身が HTTPS（TLS 1.2 以上）を提供し、ファイルを使えないときは起動しません。すべてのインターフェースよりも、このコンピューターの特定のプライベートアドレス 1 つを選んでください。受け付けるのは IPv4 アドレスのみです。初回アクセスの後、アドレスバーからトークンが消え、Cookie は HttpOnly、SameSite=Strict（HTTPS では Secure も）になります。1 分間に `listen.max_failed_attempts` 回誤ったトークンを送ったアドレスは 5 分間拒否されます。`/metrics` と `dashboard.json` はリポジトリを一覧するため、ネットワークモードではトークンが必要です。
- **GitHub 上のアクション**: **既定でオフ、アクションごとに確認、閉じたリスト**（実行やジョブの再実行、キャンセル、Issue やプルリクエストのクローズ、リストに加えた場合のプルリクエストのマージ）。ブランチやリポジトリの削除、シークレット、設定は**ありません**。AI はより小さなリスト（`rerun_failed`、`rerun_run`、`close_issue`）を提案でき、マージは決してしません。
- **act**: 既定でオフ、実行ごとに確認、`リポジトリ:ファイル:イベント` の閉じたリスト、本物のシークレットなし。クローンはワークスペース内の実在フォルダーでなければならず、他の場所へのリンクであるフォルダーは `act.allow_symlinks` がオンでない限り拒否されます。時間制限と Stop は、その実行が起動したプロセスツリー全体を終了し、作成した `act-` コンテナーを削除します。
- **自分のトークン**は、あればシステムのストアに保管されます。通常のファイル（権限 600）は最も弱い保管方法です。トークンは `gh` にのみ渡され、`act` やあなたのコマンドには渡りません。`--doctor` は保管先を表示し、トークン自体は表示しません。
- **避けるべき組み合わせ**（`--doctor` が指摘します）: すべてのインターフェースでのネットワークモード、ネットワークモード中に実行される AI アクション、ネットワークモード中の `act`、通常ファイル内のトークン。
- MCP サーバーは標準入出力のみで動作します。ネットワークポートの背後に置かないでください。

`listen.trusted_proxy`(既定でオフ):同じコンピューター上のあなた自身のリバースプロキシが唯一の入口である場合のみ。失敗した試行は、プロキシではなく `X-Forwarded-For` の最後のアドレス(あなたのプロキシが追加するもの)で数えられます。プロキシ経由のリクエストがこのコンピューターとして扱われることは引き続きありません。他の誰かがモニターに直接到達できる場合はオフのままにしてください。

## 更新ループ:ハートビートとウォッチドッグ

`/api/data` は `loop` も返します。更新サイクルの段階(`collect`、`maintain`、`publish`、`log`、`extras`、`idle`)、サイクルが続いている時間、最後に成功したサイクル、最後のエラーとその段階、再起動回数、ログや AI 向け要約の書き込みの問題です。ページ下部のバーは、サイクルが長すぎるときは赤で、ファイルを書き込めないときは警告で表示します。ウォッチドッグは、`watchdog_minutes`(既定 10、0 でオフ)を超えたサイクルを、全スレッドのトレースバックを `actions_monitor_log.txt` に書いたうえで新しいスレッドで再起動します。

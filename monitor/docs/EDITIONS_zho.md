# 完整版与 Lite: 各版型包含什么

一个软件包含两个版型。**Lite** 显示正在运行的内容、最近 24 小时的失败、历史和基础图表: 没有哨兵、没有网络模式、没有下列模块, 且不向 GitHub 写任何内容。**完整版**包含其余一切。没有第三种版型: 写入 GitHub 或访问外部的功能都在完整版中, 开启前保持关闭。完整版的使用方式 (个人、团队、服务) 另有指南。

# サウンド

ページは Web Audio API で自前の音を鳴らします。イベントの種類ごとに一つずつあるので、画面を見なくても何が起きたかを耳で区別できます。音声ファイルはありません。音はブラウザ内でオフラインで作られ、どこにも送信されません。どの音にも視覚的な通知(タイル、タブ、ラベル)があり、音がそれに代わることはありません。

| 種類 | 鳴るとき | 音 |
|---|---|---|
| 赤 | 赤でなかったワークフローが赤になる(新しい失敗)。 | 上がる二つの音。おなじみの「ビンビン」。 |
| セキュリティ・重大 | セキュリティ監視の新しいアラート、共同作業監視の重大(エラーまたはクリティカル)なアラート、見えなくなったアカウント。 | 低いパルスが三つ。 |
| 停滞 | 停滞したビルド、幽霊キュー、ランナーの問題。 | 長く下がるスライド音が一つ。 |
| スコア | フリートのスコアが下がる(`score.dropped`)。 | 下がる三つの音。 |
| 接続 | GitHub との接続、またはこのページとモニターとの接続が切れる。 | 低く長い二つの音。 |
| 警告 | レベルが警告の新しいアラート(署名待ち、古い課題、待機中のプルリクエスト)。 | 同じ中音が二つ。 |
| 解決 | 赤いワークフローが緑に戻る、または重大なアラートが消える。 | 上がる三つの音。 |
| レポート | 任意のレポートに、以前はなかった指摘が出る。 | やわらかい二つのチャイム(高い音の後に低い音)。 |
| 教訓 | 失敗の教訓に新しい分類が出る、または繰り返し始める、適用が必要になる。 | 速い高音が三つ。 |
| お知らせ | レベルが情報の新しいアラート(フォーク元のリリースなど)。 | やわらかい一つの音。 |

## ブラウザが無音になる理由と、ページの対応

- ブラウザは、ページ上でクリック、タッチ、キー入力があるまで音を鳴らさせません。それまでバーには「ブラウザが音をブロックしています。ここをクリックしてオンにします」と表示されます。どこかを一度クリックすれば解除されます。
- 音がブロックされている間に起きたことは(最長十分間)保持され、最初の機会に鳴ります。クリック、ページが前面に戻ったとき、または二秒ごとの次のチェックです。二回の取得の間に取りこぼすことはありません。十分より古いものは古い話なので知らせません。
- ページの最初の確認では、すでにあるものを記憶するだけです。数時間以内の再読み込みでも記憶が引き継がれるため、ページを閉じている間に来た失敗は新しいものとして扱われます。
- バックグラウンドのタブは、ブラウザがページを起こしている間は音が鳴ります。非表示のタブを一定時間後に停止するブラウザもあります。壁面画面とページは見える状態のウィンドウに置くのが確実です。

## 鳴りすぎない工夫

- 鳴ったばかりの種類は、`sound.cooldown_seconds`(既定 30 秒)待ってから再び鳴ります。
- 一回の確認で複数の種類が出ても一つの連続音になります。最大三つのパターンで、重大なものから先に鳴り、残りは次の連続音を待ちます。二つの連続音が重なることはありません。
- ミュートしたアラート(アラートタブ)は鳴りません。

## 設定(設定、サウンド)

すべて設定ファイルと設定タブにあります。音量、テーマ、スイッチはすぐに反映されます。

| 設定 | 内容 |
|---|---|
| `sound.enabled` | ページのすべての音の主スイッチ。 |
| `sound.on_new_red`, `sound.on_connection_lost`, `sound.on_warning`, `sound.on_resolved`, `sound.on_report`, `sound.on_lesson`, `sound.on_sentinel`, `sound.on_stuck`, `sound.on_score_drop`, `sound.on_info` | 種類ごとのスイッチ(既定はすべてオン)。 |
| `sound.theme` | `classic`(明瞭な音)または `soft`(低く丸くゆっくりした音)。どちらでも種類ごとのリズムは変わりません。 |
| `sound.volume` | 1〜100。既定は控えめ。 |
| `sound.cooldown_seconds` | 同じ種類の音の間隔。 |
| `sound.quiet_enabled`, `sound.quiet_from_hour`, `sound.quiet_to_hour` | サイレント時間(既定はオフ)。このコンピューターの二つの時刻の間は何も鳴りません。真夜中をまたげます。 |
| `sound.server_beep` | 既定はオフ。ページが開いていないときに、新しい赤をこのコンピューターのビープ音で知らせます(ローカルのみ)。 |

## 音を試す

設定の「インターフェース」では、「サウンドをテスト」ボタンが従来の「ビンビン」を鳴らし、種類ごとのボタンがその種類を設定の音量とテーマで鳴らします。下部バーの「サウンド」ラベルは、このブラウザのすべての音をミュートします。

## 壁面画面

壁面画面(`/screen/...`)も同じ音を、同じテーマ、音量、スイッチ、サイレント時間で使います。既定ではオフです。`screens.sound` をオンにし、ウィンドウに `?sound=on` が必要です。誰も触らない画面ではブラウザが求めるクリックができません。画面用ブラウザを「操作なしの音声再生を許可」するオプション(Chromium では `--autoplay-policy=no-user-gesture-required`)で起動するか、ウィンドウを一度クリックしてください。

## 保存される場所

ミュートの状態は各ブラウザが記憶し、ページが前回の確認で把握した内容もブラウザに保存されます。サウンドに関する情報はサーバーに送信されません。

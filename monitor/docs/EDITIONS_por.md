# Completa e Lite: o que há em cada edição

Há duas edições num pacote. **Lite** mostra o que está a correr, as falhas das últimas 24 horas, o histórico e gráficos básicos: sem sentinela, sem modo de rede, sem nenhum dos módulos abaixo, e não escreve nada no GitHub. **Completa** tem tudo o resto. Não há terceira edição: o que escreve no GitHub ou sai para fora está na completa, desligado até o ligar. Os modos de uso (uma pessoa, uma equipa, um serviço) têm guias próprios.

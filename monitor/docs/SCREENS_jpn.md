# 画面・サイズ・向き

ページはウィンドウの大きさ（スマートフォンから4Kまで、縦でも横でも）に合わせて変わり、1台のモニターが複数の画面を担当でき、それぞれ選んだタブを表示します。ポーリングは重複しません。すべての画面が同じ状態を読みます。

## アドレス

- `/` - ページ全体。
- `/screen/1`、`/screen/2`、`/screen/3` - その画面に設定したタブ（`ui.screen1_tabs` など）。それぞれを専用のモニターやテレビのウィンドウで開きます。
- `?orient=portrait` または `?orient=landscape` で1つのウィンドウのレイアウトを固定。`?tabs=now,charts` と `?rotate=30` で1つのウィンドウのタブと切り替え秒数を指定します。

## 設定

| 設定 | 内容 |
|---|---|
| `ui.orientation` | auto はウィンドウに従い、portrait はパネルを1列に積み、landscape は左右に並べたままにします。 |
| `ui.rotate_seconds` | 0 = オフ。複数のタブがある画面で、タブを切り替える秒数。 |
| `ui.screen1_tabs` | /screen/1 のタブ（カンマ区切り）：now, al, charts, sent, sci, scol, ssec, team, fleet, repos, rep, trep, les, hist, cfg。空 = すべて。 |
| `ui.screen1_orientation` | /screen/1 だけの auto、portrait、landscape。 |
| `ui.screen2_tabs` | /screen/2 のタブ。 |
| `ui.screen2_orientation` | /screen/2 の向き。 |
| `ui.screen3_tabs` | /screen/3 のタブ。 |
| `ui.screen3_orientation` | /screen/3 の向き。 |
| `ui.now_sort` | 並び順を選んでいない人向けの「今起きていること」の順序: ecosystem、severity、age、newest、repo、event、state。 |
| `ui.alerts_sort` | 並び順を選んでいない人向けのアラートタブの順序: server、severity、streak、class、age、newest、repo、origin、state。 |

## 一覧の並び順

最初のタブの **今起きていること** は、既定ではエコシステムごとに見出しを付けて並びます。セクション上のリストで変更できます: エコシステム、重大度(停止中、失敗したジョブがあるもの、実行中、待機中の順)、経過時間(実行時間が長い順)、新しい順、リポジトリ、トリガー(push、pull_request、schedule など)、状態(実行中を待機中より先に)。選択は人ごとに記憶されます。チームモードではサーバーがユーザーと一緒に保存し(`GET` と `POST /api/auth/me/view`、別のブラウザーでも引き継がれます)、それ以外はこのブラウザーが保存します。誰も選ばない間は設定ファイルの `ui.now_sort` が使われます(未設定または不正ならエコシステム)。 一覧の横にあるボタン **すべて展開** と **すべて折りたたむ** は、並び順に関係なく、このセクションのすべてのリポジトリを一度に展開または折りたたみます。選択は並び順と同じ場所に人ごとに記憶され、更新しても保たれます(その後に手で開閉したリポジトリはその選択を保ちます)。

**アラート**タブの一覧は、上のリストで誰かが別の順序を選ぶまで、モニターが送った順のままです。選べる順序: 重大度(重大、エラー、警告、情報)、連続失敗が長い順、区分(エラーまたは重大のアラートは実際のものとして監視対象より先)、古い順、新しい順、リポジトリ、発生元(アラートを上げたセンチネル)、状態(未対応を消音より先に)。記憶のされ方は同じで、誰も選ばない間は設定ファイルの `ui.alerts_sort` が使われます(未設定または不正なら `server`)。

## テスト済みサイズ

ブラウザテストが各サイズでページを開き、すべてのタブを巡回して、横スクロールや枠からはみ出す文字があれば失敗します。幅2400 px以上では文字が大きく（3200 px以上ではさらに大きく）なり、レイアウトを引き伸ばしません。幅より高いウィンドウではパネルを縦に積みます。

| サイズ | 種類 |
|---|---|
| 1920x1080 | Full HD |
| 2560x1080 | 21:9 |
| 3440x1440 | 21:9 |
| 5120x1440 | 32:9 |
| 3840x2160 | 4K |
| 1080x1920 | Full HD |
| 2160x3840 | 4K |
| 768x1024 | tablet |
| 390x844 | phone |

## 2〜3画面のデスク向けレシピ

1. モニターを実行しているコンピューターで、`ui.screen1_tabs` を `now,al`、`ui.screen2_tabs` を `charts,repos` にし、回転したモニターなら `ui.screen2_orientation` を `portrait` にします。
2. 1台目のモニターのウィンドウで `http://このコンピューター:8765/screen/1`、2台目で `/screen/2` を開き、F11 で全画面にします。別のコンピューターからはネットワークモードとアクセストークンを使います。
3. 誰も触れない壁面の画面には複数のタブを割り当て、`ui.rotate_seconds` を 20〜30 にします。

## 壁掛け画面：全体、いま起きていること、センチネル

だれも触らないモニターやテレビ向けの3つのページです。サイドメニューもナビゲーションもなく、すべてを大きな文字で1画面に表示し、動いているものをアニメーションで見せ、失敗はやわらかく点滅します。読み取り専用です。どのボタンも何も変更せず、GitHub も呼び出しません（モニターがすでに持っている情報を表示します）。

| アドレス | 表示内容 |
|---|---|
| `/screen/overview` | スコアのリングと文字、リポジトリ群（正常・失敗・停滞・待機）、直近24時間と7日間の面グラフ、時間帯別のリポジトリのヒートマップ、失敗が最も長く続いているもの、ランナーと分数、最新のイベント、ゲージで表した GitHub の利用枠。 |
| `/screen/now` | この1分に起きていること：進行状況と経過時間つきの実行中の実行、待機キュー、承認待ちの実行、最近の失敗、マージとリリース、予定のリリース、直近2時間のライブの流れ。 |
| `/screen/sentinels` | センチネル（A1〜A12）ごとに1枚のカード：レベル、未解決の検出数、情報源を取得できるか、最終スキャン、スキャンの進行を示すリング。問題を示すアニメーションのレーダーと、重大度別のアラート。 |

### アドレスのパラメーター

モニター1台につき1つのアドレス。パラメーターは、設定が許す範囲よりウィンドウを静かに・小さくすることはできますが、騒がしくすることはできません。

| パラメーター | 効果 |
|---|---|
| `?monitor=1`〜`9` | タイトルの横に表示される番号。 |
| `?theme=light`（または `dark`、`auto`、`contrast`、16種類のテーマ名のいずれか） | ウィンドウ全体の配色（設定より優先）。contrast は黒地に白で、遠くから見る画面向けです。 |
| `?density=compact`、`normal`、`large` | 文字サイズ。`?scale=1.5` で全体を拡大します（0.5〜3）。 |
| `?refresh=10` | 更新間隔（秒、5〜120）。 |
| `?lang=de` | 言語（en、es、de、fr、it、ja、zh、pt）。 |
| `?rotate=30` | ウィンドウが30秒ごとに「全体」「いま起きていること」「センチネル」を自動で切り替えます（最小5、0 = 1つの画面に留まる）。`screens.mode` = rotate ではすでに回転します。これは1つのウィンドウの速さを変えます。 |
| `?jump=off` | `screens.mode` = rotate のときのみ: ウィンドウは回転しますが、新しい赤へは移動しません。 |
| `?blink=off` | 失敗は点滅せず、固定の光彩で示されます。`screens.blink` がオフのものをオンにはできません。 |
| `?sound=on` | 新しい失敗で短いビープ音。`screens.sound` が許可している場合のみ。既定ではオフです。 |

### 画面の言語

画面の言語は次の順序で決まります。アドレスの `?lang=xx`、次に同じブラウザーのメインページで選んだ言語（そこに保存され、そのブラウザーで開いた画面が読み取るため、パラメーターなしで画面がページに従います）、次にモニターの言語（`MONITOR_LANG`、または設定された言語）です。保存された言語が配信された言語と異なる画面は、描画の前に一度だけ `?lang=` を付けて再読み込みし、他のパラメーター（`?rotate=` など）は保持されます。8つの言語（en、es、de、fr、it、ja、zh、pt）はページと同じで、タイトル、ラベル、状態、重大度、単位、相対時間（「5分前」）はカタログから、時刻、日付、数値は言語のロケール（en-GB、es-ES、de-DE、fr-FR、it-IT、ja-JP、zh-CN、pt-PT）で表記されます。設定の「画面を開く」リンクには、ページの言語の `?lang=` がすでに付いています。自分で言語を選ばないコンピューターは英語のままで、ブラウザーの言語では決まりません。

### 壁掛け画面の設定

| 設定 | 内容 |
|---|---|
| `screens.enabled` | 3つのページを有効にします。オフにすると `/screen/overview`、`/screen/now`、`/screen/sentinels`、`/api/screens/data` が 404 を返します（`/screen/1` から `/screen/3` はページそのもので、この設定には依存しません）。Lite エディションも壁面画面を提供しますが、センチネル画面は空です。 既定ではオフです。 |
| `screens.default_theme` | inherit（既定：製品全体で選んだテーマ。下記参照）、auto、light、dark、16種類のテーマのいずれか、contrast。 |
| `screens.default_density` | compact、normal（既定）、large。 |
| `screens.refresh_seconds` | ウィンドウの更新間隔（秒、既定は 10）。ページは GitHub ではなくモニターから読むため、短くしても利用枠は消費しません。 |
| `screens.rotate_seconds` | `screens.mode` = three のときのみ。0（既定）= 回転なし。5以上にすると1つのウィンドウが3つのページを巡回します。 |
| `screens.blink` | 失敗をやわらかく点滅させます（既定でオン）。 |
| `screens.blink_calm_minutes` | だれも対応していない失敗が点滅をやめて固定の光彩になるまでの分数（既定 30、0 = 解決するまで点滅）。 |
| `screens.sound` | 新しい失敗でビープ音を鳴らします（既定でオフ）。 |
| `screens.burn_in_protection` | 1分ごとに全体を数ピクセル動かします（既定でオン）。 |
| `screens.night_dim` | `screens.night_dim_from_hour`（22）から `screens.night_dim_to_hour`（7）まで画面を暗くします。既定ではオフです。 |
| `screens.show_repo_names` | all、public（既定：非公開リポジトリは private-1、private-2... と表示）、none（すべての名前を隠す）。他の人が見られる画面では public か none を使ってください。`repos` に手書きの一覧を使う場合、公開範囲は `discover_refresh_seconds` ごとにアカウントの一覧を 1 回読んで取得します。公開範囲を読めなかったリポジトリは非公開として扱います。 番号(private-1 など)は非表示のリポジトリにだけ付き、データフォルダー内の非公開ファイルに保存されたインストール固有の鍵による名前の HMAC の順に並びます。そのため、リポジトリが全体のどこにあるかは分かりません。 |
| `screens.theme_overview`、`screens.theme_now`、`screens.theme_sentinels` | 1つの画面のテーマ：inherit（既定：`screens.default_theme` のもの）または上記のいずれか。 |
| `screens.mode` | three（既定：3つのページを別々に、ウィンドウごとに1つ）または rotate（3つを巡回し、新しい赤へ移る1つのページ）。 |
| `screens.rotate_every_seconds` | rotate モードで各画面に留まる秒数（既定20、5～300）。 |
| `screens.alert_hold_seconds` | rotate モードで、新しい赤がウィンドウをその画面に留める秒数（既定30、5～600）。赤が消えた時点で終わります。 |
| `screens.logo_overview`、`screens.logo_now`、`screens.logo_sentinels` | ロゴを表示する画面（既定では「全体」のみ）。 |
| `screens.logo_corner` | top-right（既定）、top-left、bottom-right、bottom-left。 |
| `screens.logo_max_width`、`screens.logo_max_height` | 1920 x 1080 でのロゴの最大サイズ（ピクセル、既定 160 x 64。画面に合わせて拡大）。 |

### 画面のテーマ

モニターが表示するすべてが、設定で選んだテーマ（`ui.theme`：auto、light、dark、または16種類のテーマ）を使います。ページ、壁掛け画面、サインインページです。「このブラウザー」タブのセレクターでテーマを選ぶと `ui.theme` としても保存されるので、まだ選んでいないブラウザーはモニターのテーマを使います。ディスクに書き出される HTML レポートは、開くコンピューターのライト／ダーク設定に従います。

壁掛け画面はこれを継承します。`screens.default_theme` の既定は `inherit` です。すべての画面に同じテーマを固定するには別のテーマを設定し、1つの画面だけに専用のテーマを与えるには `screens.theme_overview`、`screens.theme_now`、`screens.theme_sentinels` を設定します。アドレスの `?theme=` で1つのウィンドウを固定することもできます。どの画面も独自の色を書き込まず、すべてテーマのパレットを使うので、ページに追加されたテーマは画面にも現れます。

### 画面のモード：3画面またはローテーション

`screens.mode` = three（既定）は3つのページをウィンドウごとに別々に保ちます。`screens.mode` = rotate では、各ウィンドウが1つの画面になり、`screens.rotate_every_seconds` 秒（既定20、5～300）ごとに「全体」「いま起きていること」「センチネル」を巡回します。

赤の障害が出ると、ウィンドウはそれを表示する画面へ移ります。失敗したワークフローは **いま起きていること**、赤くなったセンチネルのパネルは **センチネル** です。ウィンドウは `screens.alert_hold_seconds` 秒（既定30、5～600）か、その赤が消えるまでのどちらか早いほうまで留まり、その後また巡回します。すでに表示した赤は、内容が変わるか再発するまで再びウィンドウを移動させません。ウィンドウを開いたときにすでに赤いものは出発点にすぎず、移動のきっかけにはなりません。ウィンドウが最初の赤を保持している間に2つ目の赤が来た場合は、順番を待ちます。把握するために、ウィンドウは他の2つの画面を同じ読み取り専用の呼び出しでバックグラウンドから読み取ります（GitHub には接続しません）。`?rotate=0` で1つのウィンドウを1つの画面に留め、`?jump=off` で移動なしの巡回にできます。各画面は表示されるときに自分のテーマとロゴを適用します。

### 組織のロゴ

設定の「このブラウザー」タブには、組織のロゴをアップロードするブロックがあります。PNG、JPEG、WebP、または SVG で、最大 1 MB です。モニターはファイルの先頭バイトから実際の種類を確認し（名前や添付されたラベルは無視）、スクリプト、イベントハンドラー、他のファイルやアドレスへのリンク、ドキュメント型を含む SVG を拒否し、画像をこのコンピューターの `data/` フォルダーに拡張子付きの `org_logo` として保存します。設定には保存しません。ロゴは1つだけで、別のものをアップロードすると置き換わります。操作ログにはアップロードと削除が記録され、ファイルは記録されません。

`screens.logo_overview`、`screens.logo_now`、`screens.logo_sentinels` でどの壁掛け画面に表示するか（既定では「全体」のみ）、`screens.logo_corner` で隅（既定は右上）、`screens.logo_max_width` と `screens.logo_max_height` で 1920 x 1080 での最大サイズをピクセルで決めます（既定 160 x 64。ロゴは画面に合わせて拡大します）。画像は形を変えずにそのサイズに収まり、ヘッダーまたはフッターに専用の場所があるので、内容に重なることはありません。背景は透明のままです。背景が透明のロゴは、ライトテーマでもダークテーマでも適切に見えます。

### 表示するものと隠すもの

データは `/api/screens/data?screen=overview`（または `now`、`sentinels`）から取得します。直近のサイクル、センチネルのスナップショット、アラート、スコアから作られる、項目が固定されたリストです。リンク、コミットのタイトル、ジョブ名、ユーザー名、このコンピューターのパスは決して含まれず、隠したリポジトリのワークフロー名も隠されます。ネットワークモードでは、ページはモニターのほかの部分と同じアクセストークンを必要とし、応答は読み取り専用です。

### 動作

- 失敗は1秒に2回未満で点滅し（ストロボにはなりません）、新しい失敗では1回だけ光ります。`screens.blink_calm_minutes` 分のあいだだれも対応していない失敗は固定の光彩になります。システムの「視覚効果を減らす」設定や `?blink=off` では、何も点滅せず動きません。失敗は色だけで示されることはなく、記号と文字が付きます。
- モニターが応答しないときはページがそれを伝えて暗くなり、5、10、20...秒後（最大60秒）に再試行します。
- 常時点灯の画面は焼き付きから守られます。1分ごとに全体が数ピクセル動き、夜間は暗くすることもできます。

### 複数のモニターを設定する

1. モニターごとにアドレスを1つ選びます。例：`/screen/overview?monitor=1`、`/screen/now?monitor=2`、`/screen/sentinels?monitor=3`。または `?rotate=20` を付けたウィンドウを1つ開きます。
2. それぞれを Chrome または Edge のキオスクモードで開きます：`msedge --kiosk "http://このコンピューター:8765/screen/now?monitor=2" --edge-kiosk-type=fullscreen` または `chrome --kiosk "http://このコンピューター:8765/screen/now?monitor=2"`。`--kiosk` の代わりに `--app=アドレス` を使うとバーのないウィンドウになります。キオスクモードを使わない場合は、ページ下部の目立たないボタンで全画面にできます。
3. 別のコンピューターからはネットワークモードを使います。これらのページは書き込みをしないため、閲覧者のアクセストークンで十分です。

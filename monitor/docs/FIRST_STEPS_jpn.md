# 最初の5分間

**1. 必要なものを入れる。** Python 3.11 以上と GitHub CLI（`gh`）。その後一度ログインします: `gh auth login`。モニターはトークンを保存せず、`gh` に問い合わせます（設定 > 詳細設定でモニターの任意トークンをオンにした場合を除く）。

**2. 1つのコマンドで全部確認。** `python bin/actions_monitor.py --doctor` は、問題ごとに直すための正確なコマンドを表示します。先に様子を見たい場合は `python bin/actions_monitor.py --demo`。架空のデータでページが開き、`gh`・ログイン・ネットワークは不要です。

**3. 起動する。** シンプル版（ポート 8766）は `MONITOR_LITE_GITHUB_ACTIONS`、センチネル付きのフル版（ポート 8765）は `MONITOR_GITHUB_ACTIONS` をダブルクリックします。コンソールウィンドウのタイトルと1行目にどちらの版かが表示されます。

**4. ウェルカムの3ステップに従う。** 初回はページが動作の説明、アカウントで見つかった内容、基本設定への案内を表示します。既定では何も隠さず、どのグループにも属さないリポジトリは「未分類」として表示されます。

**5. ヘルプの場所を知る。** 丸い **?** ボタン（またはキー `?`）でヘルプ、**i** ボタンでバージョン情報が開き、バージョン、ファイル、サポート用情報をコピーするボタン（秘密情報は含まれません）があります。コンソールでは `--help-topics`、`--help-search 単語`、`--about`。

**6. レポートを保存または印刷する。** ページ上部の 2 つのボタンで、開いているタブのレポートを保存(TXT、PDF、必要なら JSON。いずれもブラウザーの **名前を付けて保存** ウィンドウ経由)するか、すっきりしたページとして印刷できます([他のツール向け出力](OUTPUTS.md))。

**知っておくとよいこと。** プライベートリポジトリのあるプランを使う場合は、設定 > 基本で選ぶとクォータが表示されます（[クォータとプラン](QUOTAS_jpn.md)）。センチネルについては [センチネル](SENTINEL_jpn.md) を参照してください。このツールは GitHub を読み取るだけで、確認した後にだけ書き込みます。

## 快適に読む

- **密度**(`display.density`、1つのウィンドウだけなら `?density=dense`): `dense` はすべてのタブの余白と文字を詰めます。
- **動きの抑制**(`display.reduce_motion`): `auto` はシステムの設定に従い、`on` はすべてのアニメーションと遷移を止めます。ワークフローの状態は常に言葉で書かれ、形でも描かれ、色だけで示されることはありません。
- **色覚多様性向けの配色**(`display.palette`、または `?palette=colorblind`): 青、朱色、黄、明るい青で、ダークモード用とライトモード用の2セットです。コントラストのゲート(`python tools/check_contrast.py`)がすべてのテーマを検査し、3種類の色覚多様性をシミュレートします。
- **読んでいる間は飛ばない**(`display.live_throttle_s`): ポインターやフォーカスが読んでいるタブの中にある間、定期更新は待ちます。自分で求めた更新はすぐに適用されます。
- **新機能**(`display.whats_new`): 更新後、スキップしたバージョンの変更履歴の項目がお知らせで表示されます。パレットからいつでも開き直せます。`GET /api/whats-new?since=2.1.5` が項目を返します(読み取り専用)。
- **用語集と制限**: パレットから開きます。`GET /api/glossary` が、実際のパラメーターで書かれた数値の意味、ルールが探す攻撃、分析の制限、さらに学ぶための場所を返します。`report_export.limits` をオンにすると、保存・印刷したレポートの末尾に制限が付きます。
- **ヘッダーの絞り込み**の対象は、「今」、アラート、グラフ、番人のタブ(番人、CI、コラボ、セキュリティ、配信、サプライ)、リポジトリ、履歴です。それ以外(番人の推移、チーム、フリート、レポート、教訓、更新、設定)は常に全体表示です。絞り込みの下の注記にもそう書かれます。

# クォータとプラン

モニターはあらゆる種類のアカウントで使われるため、特定のものを前提にしません。以下の数値は `monitor/quotas.json` にあり（GitHub の変更にモニターの新バージョンなしで追従するには、このファイルを編集します）、GitHub の公開ドキュメントと照合してあります。数値は時間とともに変わるため、出発点として扱い、ファイルに書かれたページを確認してください。プランは**設定 > 基本**（`account.plan`）で選びます。*不明*のあいだはクォータの数値を表示しません。

## API のクォータ

| ログイン方法 | 1時間あたりの呼び出し |
|---|---|
| ログインなし | アドレスごとに60回 |
| 自分のログイン（`gh auth login`）または個人トークン | 5,000 |
| ワークフローのトークン（Actions 内） | リポジトリごとに1,000（Enterprise Cloud は15,000） |
| Enterprise Cloud のアプリ | 15,000 |
| それ以外の GitHub App | 5,000、インストールに応じて最大12,500 |

ページは GitHub のヘッダー（`X-RateLimit-*`）から読み取った実際の上限を表示し、5,000 を決め打ちすることはありません。これにより GitHub Enterprise Server（`GH_HOST`）も動作します。ログインなし（60回/時）の場合は `gh auth login` を案内します。*セカンダリ*制限（同時100リクエストまでとバースト）もあり、GitHub がそれで応答するとモニターは最低1分待ち、待ち時間を最大5分まで倍にし、連打することはありません。

## Actions の分数

| プラン | 毎月含まれる額（金額） | Linux 換算の分数 | アーティファクト保存 |
|---|---|---|---|
| Free | $12 | 2,000 | 500 MB |
| Pro | $18 | 3,000 | 1 GB |
| Team | $18 | 3,000 | 2 GB |
| Enterprise Cloud | $300 | 50,000 | 50 GB |

**公開リポジトリはどのプランでも分数を消費しません**（セルフホストランナーも同様）。大きなランナーは常に課金されます。1分はそのシステムの料金で倍率が掛かり、Windows は Linux の約1.67倍、macOS は約10.3倍です（料金は `quotas.json` の1分あたりの額: Linux $0.006、Windows $0.010、macOS $0.062）。**設定 > 基本 > プランとクォータ**に表示されるのは**見積もり**です。直近24時間の run の所要時間を分単位に切り上げ、プライベートリポジトリのみ、`quota.default_runner` で仮定したシステムで計算し、1日のペースに月の日数を掛けます。実際の数値は、任意のスイッチ `quota.billing_api`（既定ではオフ、読み取り専用、請求を閲覧できるログインが必要）からのみ得られ、403 や 404 のときは見積もりを維持してそう表示します。含まれる分数の `quota.warn_percent`（75%）と `quota.alert_percent`（90%）に達すると、通知で月に1回ずつ警告します。

## 並行実行と上限

| プラン | 同時ジョブ数 | うち macOS |
|---|---|---|
| Free | 20 | 5 |
| Pro | 40 | 5 |
| Team | 60 | 5 |
| Enterprise | 500 | 50 |

パネルは実行中・待機中のジョブをプランの上限と比べ、90%に達したとき、または上限が埋まっているのに待機があるときに警告します。GitHub ホストのランナーでは1ジョブは最大6時間（パネルはその80%を超えたものを一覧表示）、ワークフローの run は最大35日、マトリクスは最大256ジョブです。

## 対象外のもの

追加分の単価、大きなランナー、使用中のストレージ、Codespaces、Packages は追跡しません。プランの表は出発点であり、macOS の上限は変わります。実際の請求レポートでの動作はまだ確認しておらず、`usageItems` の読み取りは公開されている説明に従い、失敗時は静かに見積もりへ戻ります。

INICIO RÁPIDO - Monitor de GitHub Actions + Centinela
=====================================================
1. Instala Python 3.11 o superior (python.org; en Linux/macOS suele estar ya: python3 --version).
2. Instala GitHub CLI (gh):
     Windows:  winget install --id GitHub.cli
     macOS:    brew install gh
     Linux:    tu gestor de paquetes (por ejemplo: sudo apt install gh) o https://cli.github.com
3. Inicia sesión una vez:  gh auth login   (elige GitHub.com y sigue los pasos en el navegador). El monitor nunca guarda un token: se lo pide a gh.
4. Arranca el monitor:
     Windows:  doble clic en MONITOR_GITHUB_ACTIONS.bat
     macOS:    doble clic en MONITOR_GITHUB_ACTIONS.command   (si no se abre: chmod +x *.sh *.command en una terminal)
     Linux:    ./MONITOR_GITHUB_ACTIONS.sh
   Se abre una página en http://127.0.0.1:8765 (solo en tu ordenador). Para parar, Ctrl+C en la ventana.
5. Primer uso:
   - La página muestra TUS repositorios (la cuenta de GitHub con la que iniciaste sesión). Para vigilar otra cuenta pon "github_owner" en actions_monitor.json.
   - Elige tu idioma en la pestaña Configuración de la página (icono del engranaje; arranca en inglés y la elección se recuerda). Allí están también los demás ajustes.
   - Para agrupar repositorios por prefijo de nombre o usar las herramientas de lote, copia ecosystems.example.json / targets.example.json y apunta
     actions_monitor.json a ellos ("ecosystems_file", "targets_file"). El detalle está en README_es.txt.
   - ¿Sin clones locales? Funciona igualmente, en modo reducido (solo lo que da la API de GitHub), y la página te lo dice.
6. Lo que NO hace: no firma y no publica nada por sí solo, por sí solo no escribe nada en GitHub (solo `dispatch --go`, `dispatch --real` y `finalize --execute`, que ejecutas tú, lo hacen), solo escucha en 127.0.0.1 y no guarda ningún token. Firmar y publicar son
   comandos que ejecutas tú; el monitor solo los muestra como texto.
7. Extras opcionales (apagados o aparte): lint_workflows.py revisa tus archivos de workflow antes de subir; tui.py muestra una cuadrícula en vivo en la consola (pip install rich); las notificaciones, el webhook de entrada y el
   asistente de IA se activan en la pestaña Configuración; para ejecutarlo como servicio, tras un proxy o en un contenedor mira docs/DEPLOYMENT_spa.md.
¿Problemas? Mira «PROBLEMAS» en README_es.txt.

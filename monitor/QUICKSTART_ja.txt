クイックスタート - GitHub Actions モニター + センチネル
=====================================================
1. Python 3.11 以上をインストールします（python.org。Linux/macOS では通常すでに入っています: python3 --version）。
2. GitHub CLI（gh）をインストールします:
     Windows:  winget install --id GitHub.cli
     macOS:    brew install gh
     Linux:    お使いのパッケージマネージャー（例: sudo apt install gh）または https://cli.github.com
3. 一度だけログインします:  gh auth login   （GitHub.com を選び、ブラウザーの手順に従います）。モニターはトークンを保存せず、gh に尋ねます。
4. モニターを起動します:
     Windows:  MONITOR_GITHUB_ACTIONS.bat をダブルクリック
     macOS:    MONITOR_GITHUB_ACTIONS.command をダブルクリック（開けない場合はターミナルで chmod +x *.sh *.command）
     Linux:    ./MONITOR_GITHUB_ACTIONS.sh
   http://127.0.0.1:8765 にページが開きます（このコンピューター上だけ）。停止はウィンドウで Ctrl+C。
5. 最初の使い方:
   - ページには「あなたの」リポジトリ（ログインした GitHub アカウント）が表示されます。別のアカウントを監視するには actions_monitor.json の "github_owner" を設定します。
   - 言語はページの「設定」タブ（歯車アイコン）で選びます。起動時は英語で、選択は記憶されます。ほかの設定もそこにあります。
   - 名前の接頭辞でリポジトリをまとめたり、バッチツールを使ったりするには、ecosystems.example.json / targets.example.json をコピーし、
     actions_monitor.json の "ecosystems_file" と "targets_file" で指定します。詳細は README_ja.txt にあります。
   - ローカルクローンがなくても、縮小モード（GitHub API が返す情報だけ）で動作し、ページがその旨を表示します。
6. しないこと: 自動で署名・公開することはなく、単独では GitHub に何も書き込まず（書き込むのは、あなたが実行する `dispatch --go`、`dispatch --real`、`finalize --execute` だけ）、127.0.0.1 でのみ待ち受け、トークンも保持しません。署名と公開はあなた自身が実行する
   コマンドで、モニターはそれをテキストとして表示するだけです。
7. 任意の追加機能(オフまたは別扱い):lint_workflows.py は push の前にワークフローファイルを検査し、tui.py はコンソールにライブ表を表示します(pip install rich)。通知、受信 Webhook、AI アシスタントは設定タブでオンにします。
   サービス、プロキシの背後、コンテナーでの運用は docs/DEPLOYMENT_jpn.md を参照してください。
困ったときは README_ja.txt の「困ったとき」を参照してください。
